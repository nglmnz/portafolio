TRANSPARENCIA DIGITAL

Privacidad y analítica de visitas

Este es un portafolio académico y profesional alojado en GitHub Pages. Mi objetivo al medir su audiencia es comprender qué investigaciones y proyectos despiertan interés, no identificar a las personas que navegan por la web.

Qué se mide

El sitio utiliza Cloudflare Web Analytics, un servicio de estadísticas agregadas de páginas visitadas, fuentes de referencia, país aproximado, navegador, dispositivo y rendimiento. Según Cloudflare, su analítica web no utiliza cookies ni técnicas de seguimiento individual de visitantes.

Desde el 2 de noviembre de 2026, la medición está activada mediante un token público válido en el archivo assets/analytics-config.js. Las nuevas visitas se miden con el script de Cloudflare en las páginas del portafolio; al retirar el token se desactiva. El token puede consultarse en el código público, pero no da acceso al panel privado de estadísticas.

Qué no se hace

No se crea un perfil individual ni se conoce el nombre, correo o identidad de una persona por el hecho de visitar la página. No se instalan cookies de identificación propias ni se usa una huella digital del navegador para seguir a alguien. No se han configurado eventos de seguimiento de clics individuales ni formularios de captación obligatorios.

Contenido externo

Las páginas pueden incluir enlaces a GitHub, artículos, investigaciones y otros sitios externos. La entrevista con Breno Bringel en ALAS utiliza un reproductor de YouTube en modo de privacidad mejorada (youtube-nocookie.com): ese reproductor no se solicita hasta que alguien elige reproducir el video. A partir de ese momento se aplica también la política de privacidad del proveedor externo.

Alojamiento y límites

GitHub Pages aloja la página; GitHub puede procesar datos técnicos de acceso para prestar el servicio conforme a sus propias condiciones. Las estadísticas de la plataforma de analítica son estimaciones de tráfico y pueden omitir visitas bloqueadas por configuraciones del navegador.

Contacto y modificaciones

Si tienes consultas sobre esta página, utiliza los datos de contacto publicados en el portafolio. Esta información se actualizará si cambian el proveedor de analítica, las finalidades o los servicios externos utilizados.
